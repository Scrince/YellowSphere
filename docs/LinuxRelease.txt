YellowSphere v1.6.6 - Linux Release Notes
=============================================

Release status
--------------

This file records the published v1.6.6 Linux artifacts with their measured
filenames, metadata, and hashes. YellowSphere.html v1.6.6 is the promoted
production source. See Release_v1.6.6.txt for the completed release checklist.

Scope
-----

This document records Linux-specific release, installation, verification, and
operational notes for the v1.6.6 Tauri desktop build.

The canonical application remains YellowSphere.html v1.6.6. The Linux Tauri
build packages that same offline application inside a native WebKitGTK desktop
wrapper with the Tauri save_export bridge.


Release Artifacts
-----------------

The v1.6.6 Linux release set currently contains amd64 artifacts only:

  releases/tauri/linux/yellowsphere
  releases/tauri/linux/YellowSphere_1.6.6_amd64.deb
  releases/tauri/linux/YellowSphere-1.6.6-1.x86_64.rpm

The binary artifact is an x86-64 Linux ELF executable. The Debian package is
for amd64 systems. The RPM package is for x86_64 systems.

No Linux arm64/aarch64 package was produced for this release.

No AppImage artifact is part of the v1.6.6 Linux release set. The v1.6.6 build
published only the raw ELF, .deb, and .rpm files. The earlier v1.6.0 AppImage
retry reached Tauri's linuxdeploy packaging step and failed inside the Docker
amd64 build environment.

Debian or Ubuntu Installation
-----------------------------

Install the .deb package with:

  sudo apt install ./releases/tauri/linux/YellowSphere_1.6.6_amd64.deb

or:

  sudo dpkg -i ./releases/tauri/linux/YellowSphere_1.6.6_amd64.deb
  sudo apt -f install

The package declares these runtime dependencies:

  libwebkit2gtk-4.1-0
  libgtk-3-0

If the host distribution does not provide WebKitGTK 4.1 packages, use a
distribution release that does or run the standalone HTML application directly
in an offline browser.


RPM Installation
----------------

Install the RPM package on Fedora-like systems with:

  sudo dnf install ./releases/tauri/linux/YellowSphere-1.6.6-1.x86_64.rpm

On systems using rpm directly:

  sudo rpm -i ./releases/tauri/linux/YellowSphere-1.6.6-1.x86_64.rpm

The RPM is unsigned, so hash verification is mandatory before installation.


Standalone Binary Use
---------------------

The raw Linux binary can be run directly on compatible amd64 Linux systems with
the required WebKitGTK and GTK runtime libraries installed:

  chmod +x releases/tauri/linux/yellowsphere
  ./releases/tauri/linux/yellowsphere

The standalone binary is useful for controlled testing, but package
installation is preferred for normal desktop launcher integration and runtime
dependency handling.


Operational Notes
-----------------

Linux desktop packaging does not change the recovery security model:

  - The application still handles mnemonic words and private key material.
  - The Tauri wrapper still passes exports through native save_export.
  - Exported JSON, CSV, TXT, PDF, .arc, keyfile, and QR files are ordinary
    filesystem writes.
  - Browser and WebView memory are not hardened secret vaults.
  - The host clipboard, display server, crash reporting, shell history, and
    filesystem remain part of the security boundary.

For high-value recovery, use an offline Linux environment, disable networking
and sync services, avoid remote desktop sessions, verify hashes before launch,
export only the required artifacts, and clear the session before shutdown.


Build Reference
---------------

The v1.6.6 Linux amd64 release was built in a Linux amd64 Docker environment
from the prepared Tauri assets without editing HTML files.

The package build command was:

  cargo tauri build --bundles deb,rpm --ci

No AppImage command was run for v1.6.6. Do not document an AppImage as
available unless a future release successfully produces and verifies one.
