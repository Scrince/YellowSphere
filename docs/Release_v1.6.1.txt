YellowSphere v1.6.1 - Release Notes
==============================

Release date: 2026-06-17

Production file
---------------

  YellowSphere.html

The production HTML reports APP_VERSION 1.6.1 and displays "YellowSphere v1.6.1".
It supersedes the former YellowSphere_Beta.html filename.

Archived browser builds
-----------------------

  lts/YellowSphere_v1.6.0_LTS.html
  lts/YellowSphere_v1.5.0_LTS.html

The v1.6.0 archive displays "YellowSphere v1.6.0 LTS". The detailed
v1.6.0 byte-level specifications elsewhere in docs/ remain the compatibility
baseline for that archived build and for unchanged YellowSphere ARC V2 behavior.

Supported production currencies
-------------------------------

  Bitcoin
  Bitcoin Cash
  Litecoin
  Dogecoin
  Ethereum / ERC-20
  BNB Chain
  Avalanche C-Chain
  Polygon
  Cosmos / ATOM
  Tron / TRC-20
  Solana
  Stellar
  Cardano
  XRP

Polkadot and Monero are not supported by the v1.6.1 production browser build.

Polygon
-------

Polygon uses Ethereum-compatible secp256k1 account keys, EIP-55 checksummed
0x addresses, and the default account path:

  m/44'/60'/0'

The Advanced Testnet setting selects Polygon Amoy metadata. Address derivation
is identical across Polygon mainnet and Amoy for the same mnemonic,
passphrase, and path.

Compatibility boundary
----------------------

YELLOWSPHERE-ARC-V2 seed import/export, keyfile modes, BIP39 handling, PDF/JSON/
CSV/TXT exports, and QR rendering retain the v1.6.0 format behavior unless a
v1.6.1 release note explicitly states otherwise.

The Python GUI package and packaged WebView asset are promoted to v1.6.1 and
embed the production browser code. The Python CLI derivation engine remains a
separate compatibility surface. The Windows Tauri executable, MSI, and NSIS
installer are rebuilt as v1.6.1 from the same production browser code; the
previously published macOS and Linux native artifacts remain on their v1.6.0
line. Do not assume the CLI coin choices match the v1.6.1 browser GUI.

Windows Tauri release
---------------------

The v1.6.1 Windows x64 release set is:

  releases/tauri/windows/yellowsphere.exe
  releases/tauri/windows/YellowSphere_1.6.1_x64_en-US.msi
  releases/tauri/windows/YellowSphere_1.6.1_x64-setup.exe

The installers are locally built and are not Authenticode-signed. Verify their
SHA-256 values against docs/SHA256SUMS before use. The raw executable and both
installers embed the Tauri/WebView wrapper around YellowSphere.html v1.6.1.

The recorded Windows build environment was:

  Windows: 10.0.26200.8457 (x64)
  rustc: 1.96.0 (ac68faa20 2026-05-25)
  cargo: 1.96.0 (30a34c682 2026-05-25)
  tauri-cli: 2.11.2

The build commands were:

  powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\prepare-tauri-assets.ps1
  cargo tauri build --bundles msi,nsis --ci

Verification confirmed the prepared Tauri HTML reports APP_VERSION 1.6.1, the
raw executable opens an "YellowSphere" window, the MSI ProductVersion is
1.6.1, and all three published Windows artifacts are unsigned as documented.
