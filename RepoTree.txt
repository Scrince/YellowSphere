Production notes:

  The canonical standalone browser application is YellowSphere.html. It runs
  directly as a local file and does not require a build step or network access.
  The Python GUI packages its own HTML and runtime assets under
  src/yellowsphere/assets/. Tauri uses the prepared frontend in tauri-dist/;
  its preparation scripts are development/build tooling and are intentionally
  outside this production tree.

  The repository also ships Python and Tauri packages under releases/ and
  retains earlier standalone browser builds under lts/. Package versions and
  platform contents can vary by release; consult README.md and the relevant
  user documentation for current support details.

  This map omits development and build environment files such as tests,
  workflows, build scripts, dependency lockfiles, generated schemas, caches,
  temporary files, and intermediate outputs. It also omits credentials,
  private keys, signing material, and secret-bearing files or values.
